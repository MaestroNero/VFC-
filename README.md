# VFC — Video Frame Cipher

VFC هو مشروع تعليمي Python يطبق نظام تشفير وإخفاء داخل الفيديو (video steganography) باستخدام صورة إطار محدد من الفيديو وكلمة مرور، بهدف إخفاء ملف مشفر داخل مسار الصوت، ثم استخراج الملف لاحقًا من الفيديو المعدّل.

## ما هو المشروع؟

الفكرة الأساسية للمشروع هي ربط عدة طبقات معًا:

- استخراج بصمة إطار الفيديو (frame fingerprint) من إطار محدد
- اشتقاق مفاتيح التشفير من كلمة المرور + البصمة + معلومات الإطار
- تشفير البيانات باستخدام تصميم تشفير مخصص (custom block cipher)
- تجهيز الحمولة (payload) وإضافة بيانات التحقق
- إخفاء البيانات داخل تيار الصوت في الفيديو باستخدام تقنيات LSB
- استخراج الملف المخفي واسترجاعه في الطرف الآخر

هذا المشروع مناسب للتعلم والشرح العملي في مجالات:

- أمن المعلومات
- إخفاء البيانات (steganography)
- التشفير المخصص
- تصميم أنظمة الفيديو الآمنة تعليمياً

## مكونات المشروع

- `vfc/` : الكود الأساسي للمشروع
  - `core.py` : التشغيل العام للخطوات الأساسية
  - `cipher.py` : خوارزمية التشفير المخصصة
  - `keys.py` : اشتقاق المفاتيح
  - `fingerprint.py` : استخراج بصمة الإطار
  - `payload.py` : تنسيق الحمولة والبيانات المرفقة
  - `stego.py` : إخفاء البيانات داخل الصوت
  - `video.py` : التعامل مع ملفات الفيديو الحقيقية
- `vfc_gui.py` : واجهة رسومية
- `vfc/vfc_cli.py` : واجهة سطر أوامر
- `academic-kit/` : نسخة تعليمية/تفاعلية للشرح المرئي

## التشغيل السريع

### 1) تشغيل الواجهة الرسومية

```bash
python3 vfc/vfc_cli.py gui
```

أو:

```bash
python3 vfc_gui.py
```

### 2) تشفير ملف داخل فيديو

```bash
python3 vfc/vfc_cli.py encrypt -i carrier.mkv -s secret.pdf -o stego.mkv -f 30
```

### 3) استخراج الملف المخفي

```bash
python3 vfc/vfc_cli.py decrypt -i stego.mkv -o out_dir -f 30
```

ملاحظة: يمكن إدخال كلمة المرور عبر متغير البيئة `VFC_PASSWORD` أو سيتم طلبها تلقائياً عند التشغيل.

## مثال عملي

```bash
export VFC_PASSWORD="MyStrongPassword"
python3 vfc/vfc_cli.py encrypt -i carrier.mkv -s secret.txt -o stego.mkv -f 30
python3 vfc/vfc_cli.py decrypt -i stego.mkv -o recovered -f 30
```

## ملاحظات مهمة

- المشروع يدعم الفيديوهات التي يمكنها حمل صوت غير مضغوط / PCM في حاوية مناسبة مثل MKV.
- الهدف من المشروع تعليمي بحت، ولا يُقصد به استخدامه كحل تشفير إنتاجي حقيقي.
- يتم اعتماد إطار محدد من الفيديو كجزء من عملية اشتقاق المفاتيح، ما يضيف طبقة مرتبطة بالمحتوى البصري للفيديو.
